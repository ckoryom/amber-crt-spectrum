## [0.0.1-alpha.0] - 2026-07-25

### Added

- Initial Amber CRT Spectrum release with a warm phosphor-inspired workbench palette.
- Expanded workbench theming for the explorer, tabs, panels, menus, quick pick, notifications, terminal, extension pages, and other common VS Code surfaces.
- Vivid syntax and semantic highlighting tuned for code readability across everyday development workflows.
- Extension branding assets, committed screenshots, and a polished Marketplace-ready README.
- Local packaging support for VS Code via `vsce`, plus one-command build-and-install developer scripts.
- pnpm-based dependency management with audit checks.
- GitHub Actions for CI, CodeQL, Dependabot, Release Please automation, Entra OIDC validation, and Marketplace publishing.
